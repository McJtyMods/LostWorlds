# LostWorlds
Lost worlds is a worldgen mod that works well together with Lost Cities

For floating cities above an ocean, choose the Lost Worlds **Islands** world type and the Lost Cities `floating` profile. Set the sea level in Lost Worlds' **Customize** screen. The seabed follows sea levels below Y=0, so Y=−40 still leaves an ocean beneath the islands. **Off** leaves the space beneath the islands empty.
